## Overview
This project aims to create a simple differential drive robot in Gazebo and then visualizing it in RViz2.

In this project, one can learn to:
1) Write a URDF file to define the links and joints of a robot
2) How to add sensors onto the robot through the URDF file
3) How to bridge Gazebo Topics to ROS2 and vice versa
4) How to create and build a ROS2 Workspace using ``colcon-build``
